# EQUILIBRIO

Web app interattiva (italiano) per riconoscere e gestire lo stress: percorso 30 giorni, diario, metodo S.T.A.R., strumenti, progressi e biblioteca. Dati locali su `localStorage`.

## Stack

Next.js (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Zustand · Lucide · Recharts · React Hook Form + Zod · date-fns · Motion · jsPDF

## Avvio locale

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run lint
```

## Privacy

Nessun account obbligatorio. Nessuna API a pagamento. Export/import JSON dal Profilo. Stub Supabase presente solo per architettura futura.
